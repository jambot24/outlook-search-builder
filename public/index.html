    Where to paste the query
    • Outlook Classic (Windows): click the search box above the message list, paste, press Enter. Use the scope dropdown next to the box for "Current folder", "All mailboxes" and so on.
    • New Outlook and Outlook on the web: paste into the search box at the top of the window.
    • Outlook for Mac: paste into the search box at the top of the window.
    • Outlook mobile (iPhone, iPad, Android): tap Search, paste the query, then tap the search key.
    If a search finds nothing
    1. Check the scope first. A correct query returns nothing when the search is limited to the wrong folder, mailbox or account. New Outlook cannot search several accounts at once, so select each account and search All folders.
    2. Start simple. Remove criteria one at a time until the message appears, then add them back.
    3. Use full email addresses instead of display names.
    4. Use numeric dates. Newer builds no longer accept weekday or month names such as "Tuesday" or "March".
    5. Check Deleted Items. Whether it is searched is a setting in each version of Outlook.
    6. Shared mailboxes in Outlook Classic: select the shared mailbox's folder and use Current folder. "All mailboxes" can return nothing for shared mailboxes.
    7. Outlook Classic only: under Search Tools > Indexing Status, confirm indexing has finished. Then try the same query in Outlook on the web. If the web finds the message and Classic does not, the problem is the local search index, not the query.
